# HelpDesk – Front-end (React + Vite)

1. `npm install`
2. Lancer l'API sur `localhost:3000`, puis `npm run dev` → http://localhost:5173
3. Les appels `/api/...` passent par le proxy Vite (pas de CORS).

Données fictives (incidents, utilisateurs) : `src/mock.js` – à remplacer quand les routes des incidents seront livrées.
